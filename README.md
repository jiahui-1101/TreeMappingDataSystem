# TBJ Tree Mapping System

Modular Vite React UI prototype for the Johor Botanical Garden Tree Mapping Data System.

## Run locally

```bash
npm install
npm run dev
```

Demo accounts:

| Role | ID | Password |
| --- | --- | --- |
| Admin | `admin001` | `admin123` |
| Ranger | `RGR001` | `ranger123` |
| Visitor | `visitor@gmail.com` | `visitor123` |
| IT Support | `it001` | `support123` |

Visitors can also continue as guests. Collection history and language choice are stored in browser `localStorage`.

## Verify

```bash
npm run test
npm run build
```

This repository is a frontend UI prototype. Backend authentication, database synchronization, AI API calls, QR endpoint generation, GPS validation, push notifications, and server-side audit persistence are represented by mock UI states only.
